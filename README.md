# algoritmia-riwi

Ejercicios de algoritmia del curso de Riwi, escritos en pseudocódigo **PSeInt** (`.psc`).

## Estructura

### Semana 1 — Secuencias (entrada, proceso, salida)

| Archivo | Descripción |
|---|---|
| [saludo.psc](semana%201/saludo.psc) | Pide nombre y apellido y saluda. |
| [EdadEnDias.psc](semana%201/EdadEnDias.psc) | Convierte la edad en años a días (`edad * 365`). |
| [PromedioNotas.psc](semana%201/PromedioNotas.psc) | Promedio de tres notas. |
| [Promediocuenta.psc](semana%201/Promediocuenta.psc) | Divide una cuenta con propina (%) entre varias personas. |
| [tinto.md](semana%201/tinto.md) | Algoritmo en lenguaje natural para preparar un tinto. |

### Semana 2 — Condicionales (`Si / SiNo`)

| Archivo | Descripción |
|---|---|
| [bisiesto.psc](semana%202/bisiesto.psc) | Determina si un año es bisiesto. |
| [validadedad.psc](semana%202/validadedad.psc) | Valida que la edad esté entre 0 y 120. |
| [validarregistro.psc](semana%202/validarregistro.psc) | Permite registro si edad ≥ 14 y acepta términos. |
| [semaforo.psc](semana%202/semaforo.psc) | Clasifica unidades en estado (negativo / 0 / amarillo ≤ 10 / verde). |
| [parqueadero.psc](semana%202/parqueadero.psc) | Calcula el cobro de parqueadero según tipo de vehículo (carro/moto) y tiempo. |

### Semana 3 — Ciclos (`Mientras`, `Para`, `Repetir`)

| Archivo | Ciclo | Descripción |
|---|---|---|
| [cajeroParqueadero.psc](semana%203/cajeroParqueadero.psc) | `Mientras` | Suma cobros hasta ingresar 0 (cierre de caja); muestra carros atendidos y total recaudado. |
| [Calificaciones.psc](semana%203/Calificaciones.psc) | `Para` | Lee 5 notas; calcula promedio, aprobados (≥ 3), nota mayor y menor, y avisa si alguien perdió. |
| [facturaRestaurante.psc](semana%203/facturaRestaurante.psc) | — | Factura con propina del 10%: subtotal, propina, total y total por persona. |
| [PIramide.psc](semana%203/PIramide.psc) | `Para` anidado | Dibuja una pirámide de `*` de altura `n`. |
| [ValidarPIN.psc](semana%203/ValidarPIN.psc) | `Repetir … Hasta Que` | Pide el PIN (1234) hasta acertar o agotar 3 intentos. |

## Cómo ejecutar

1. Instalar [PSeInt](https://pseint.sourceforge.net/).
2. Abrir el archivo `.psc` y ejecutar con **F9**.
